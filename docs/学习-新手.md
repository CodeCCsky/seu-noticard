## 2. 语法最小集（每天一个主题）

### 2.1 变量

~~~cpp
int age = 20;              // 整数
double score = 91.5;       // 小数
char grade = 'A';          // 单个字符，用单引号
bool pass = true;          // true / false
std::string name = "SEU";  // 字符串，用双引号，要 #include <string>
~~~

**练习**：定义三个变量，打印出来。

### 2.2 输出

~~~cpp
#include <iostream>

int main() {
    int a = 3;
    std::cout << "a = " << a << std::endl;
    return 0;
}
~~~

- `std::cout <<` 是"往屏幕写"；
- `std::endl` 是换行；
- 每一句结尾必须有分号 `;`。

### 2.3 `if`

~~~cpp
int score = 85;

if (score >= 90) {
    std::cout << "A";
} else if (score >= 80) {
    std::cout << "B";
} else {
    std::cout << "C";
}
~~~

注意：`=` 是赋值，`==` 才是比较。这是新手第一大坑。

### 2.4 `for` 和 `while`

~~~cpp
int sum = 0;
for (int i = 1; i <= 100; ++i) {
    sum += i;
}
std::cout << sum;      // 5050
~~~

~~~cpp
int n = 3;
while (n > 0) {
    std::cout << n;
    --n;
}
~~~

**练习**：打印 1 到 10；打印 10 到 1；求 1 到 100 的偶数和。

### 2.5 函数

~~~cpp
int add(int a, int b) {
    return a + b;
}

int main() {
    std::cout << add(2, 3);   // 5
    return 0;
}
~~~

- 函数 = 名字 + 参数 + 返回类型；
- `return` 把结果交回去；
- 函数要写在 `main` 前面，或者在前面先声明。

### 2.6 `std::vector`（可变长数组）

~~~cpp
#include <vector>
#include <iostream>

int main() {
    std::vector<int> v;
    v.push_back(3);
    v.push_back(5);
    std::cout << v.size() << std::endl;   // 2
    std::cout << v[0] << std::endl;       // 3

    for (int x : v) {
        std::cout << x << " ";
    }
    return 0;
}
~~~

### 2.7 `struct`（把几个字段打包）

~~~cpp
#include <string>
#include <vector>
#include <iostream>

struct Item {
    std::string title;
    std::string date;
};

int main() {
    Item it;
    it.title = "选课通知";
    it.date = "2026-09-01";

    std::vector<Item> items;
    items.push_back(it);
    std::cout << items[0].title << std::endl;
    return 0;
}
~~~

### 2.8 `std::string` 常用操作

~~~cpp
std::string s = "hello";
s.size();            // 5
s[0];                // 'h'
s.find("ll");        // 2，找不到返回 std::string::npos
s.substr(1, 3);      // "ell"
s += " world";       // 变成 "hello world"
~~~

**注意**：一个汉字在 `std::string` 里占 3 个字节，`s.size()` 数的是字节，不是字数。

### 2.9 引用（函数里改外面的变量）

~~~cpp
void add_one(int& x) {   // & 表示"引用"，不是复制
    x = x + 1;
}

int main() {
    int a = 5;
    add_one(a);
    std::cout << a;      // 6
    return 0;
}
~~~

只读参数写 `const std::string&`：不复制，也不能改。

### 2.10 类（先学会读）

~~~cpp
class Counter {
public:
    Counter() { n_ = 0; }        // 构造函数：创建时执行
    void add(int k) { n_ = n_ + k; }
    int value() const { return n_; }
private:
    int n_;
};

int main() {
    Counter c;
    c.add(3);
    std::cout << c.value();      // 3
    return 0;
}
~~~

你暂时不用写类，只要能读懂 `Db`、`Http` 的头文件就行。

## 3. 你的第一个任务：`trim`

**需求**：去掉字符串两端的空格、制表符、回车、换行。

**思路**（先画出来再写）：

~~~
"  abc  "
 ^     ^
 b     e
结果 = s.substr(b, e - b + 1)
~~~

**代码**：

~~~cpp
#include <string>

std::string trim(const std::string& s) {
    const std::string space = " \t\r\n";
    std::size_t b = s.find_first_not_of(space);
    if (b == std::string::npos) {
        return "";
    }
    std::size_t e = s.find_last_not_of(space);
    return s.substr(b, e - b + 1);
}
~~~

**测试**：

~~~cpp
#include <iostream>

int main() {
    std::cout << "[" << trim("  abc  ") << "]" << std::endl;   // [abc]
    std::cout << "[" << trim("   ") << "]" << std::endl;       // []
    std::cout << "[" << trim("") << "]" << std::endl;          // []
    return 0;
}
~~~

**验收**：三个用例都过；你能解释 `npos` 是什么、`substr` 第二个参数是什么。


## 4. 第二个任务：`lower_ascii`

**需求**：把大写字母变小写，中文和其他字符不动。

~~~cpp
std::string lower_ascii(const std::string& s) {
    std::string result = s;
    for (std::size_t i = 0; i < result.size(); ++i) {
        if (result[i] >= 'A' && result[i] <= 'Z') {
            result[i] = result[i] - 'A' + 'a';
        }
    }
    return result;
}
~~~

**为什么不能直接用 `tolower`**：它依赖 locale，对 UTF-8 字节可能出错。手动判断 ASCII 范围最稳。

## 5. 第三个任务：`decode_entities`

**需求**：把 HTML 实体换成字符：`&amp;` → `&`，`&lt;` → `<`，`&nbsp;` → 空格。

~~~cpp
std::string decode_entities(const std::string& s) {
    std::string result;
    std::size_t i = 0;
    while (i < s.size()) {
        if (s[i] == '&') {
            if (s.compare(i, 5, "&amp;") == 0)  { result += '&';  i += 5; continue; }
            if (s.compare(i, 4, "&lt;") == 0)   { result += '<';  i += 4; continue; }
            if (s.compare(i, 4, "&gt;") == 0)   { result += '>';  i += 4; continue; }
            if (s.compare(i, 6, "&quot;") == 0) { result += '"';  i += 6; continue; }
            if (s.compare(i, 6, "&nbsp;") == 0) { result += ' ';  i += 6; continue; }
            if (s.compare(i, 5, "&#39;") == 0)  { result += '\''; i += 5; continue; }
        }
        result += s[i];
        ++i;
    }
    return result;
}
~~~

**易错点**：`&lt;` 是 4 个字符，不是 5；`i += 4` 别写错。

## 6. 第四个任务：`strip_tags`（状态机）

**需求**：把 HTML 标签去掉，只留文字。

**思路**：维护一个布尔值 `in_tag`——看到 `<` 就进入标签，看到 `>` 就离开。

~~~cpp
std::string strip_tags(const std::string& html) {
    std::string out;
    bool in_tag = false;
    for (std::size_t i = 0; i < html.size(); ++i) {
        char c = html[i];
        if (c == '<') {
            in_tag = true;
            continue;
        }
        if (c == '>') {
            in_tag = false;
            out += ' ';
            continue;
        }
        if (!in_tag) {
            out += c;
        }
    }
    return out;
}
~~~

这是**简化版**，能去掉标签，但还不会：

- 跳过 `<script>` / `<style>` 里的内容；
- 把 `<br>`、`</td>` 变成换行；
- 解实体。

这些是下一步，主程会带你做。先让这个版本跑通，再逐步加。

## 7. 读文件（为测试做准备）

~~~cpp
#include <fstream>
#include <sstream>
#include <iostream>

std::string read_all(const std::string& path) {
    std::ifstream in(path.c_str(), std::ios::binary);
    if (!in) {
        return "";
    }
    std::ostringstream ss;
    ss << in.rdbuf();
    return ss.str();
}

int main() {
    std::string html = read_all("fixtures/list_jwc_jwxx_20261102.htm");
    std::cout << html.size() << std::endl;   // 应该是 40008
    return 0;
}
~~~

**注意**：相对路径是相对于"运行时的工作目录"，不是源文件。VS 里：项目 → 属性 → 调试 → 工作目录，设成仓库根目录。

## 8. Git 最小集

~~~text
git status                    # 看我改了哪些文件
git add src/utils/text.cpp    # 把某个文件加入本次提交
git commit -m "实现 trim"     # 提交
git pull                      # 拉别人的改动
git push                      # 推到远端
~~~

分支：

~~~text
git checkout -b feat/text     # 新建并切换到自己的分支
~~~

规矩：

- 一次提交只做一件事；
- 提交前先 `git status`，确认没有把 `build/`、`.db` 提交进去；
- 不确定的时候不要 `git push -f`。

### 9.3 JS：拿数据、画卡片

~~~js
fetch('/api/items')
  .then(function (r) { return r.json(); })
  .then(function (data) { render(data.items); });

function render(items) {
  var box = document.getElementById('cards');
  box.innerHTML = '';
  for (var i = 0; i < items.length; i++) {
    var it = items[i];
    var card = document.createElement('div');
    card.className = 'card';
    card.style.animationDelay = (i * 40) + 'ms';

    var title = document.createElement('h3');
    title.textContent = it.title;
    card.appendChild(title);

    var summary = document.createElement('p');
    summary.textContent = it.summary || '';
    card.appendChild(summary);

    box.appendChild(card);
  }
}
~~~

**为什么不用 `innerHTML` 拼字符串**：数据来自网页，可能带 `<script>`，会把页面搞坏。`textContent` 只当文字。

### 9.4 没有后端时怎么开发

主程会给你一份 `mock.json`。在 `web/` 目录下起一个静态服务器：

~~~text
python -m http.server 8000
~~~

浏览器打开 `http://127.0.0.1:8000`，把 `fetch('/api/items')` 临时改成 `fetch('/mock.json')`，界面就能先做起来。

## 11. 卡住了怎么问

一条好问题包含四样东西：

1. **你想做什么**（一句）；
2. **你写了什么**（贴最小那段代码，不要整个文件）；
3. **实际发生了什么**（报错原文，或截图）；
4. **你已经试过什么**。

反例："我这个跑不起来，怎么办？"
正例："我想读 fixtures 里的文件，代码是……，运行后窗口一闪而过，我试过改路径和加断点，断点没停。"
